# TT播放器 桌面宠物素材生成提示词（豆包专用）

> 参考成熟开源桌宠项目 dsh-pet（大肥鱼桌宠，GitHub 4600+ star）的素材配方，
> 该项目全部动画素材即由豆包生成。本篇按「真猫四足」重写，适配本播放器。
>
> **三条铁律（务必遵守）**
> 1. 猫咪必须是**正常的四足猫咪形象**，不是拟人直立，不穿衣服，不做人类动作。
> 2. 描述猫咪表情时**禁止使用「（笑脸）」「(开心)」这类括号注释词**，
>    一律用具体的五官描述（眼睛形状、耳朵角度、嘴形、尾巴状态）。
> 3. **必须先生成 360° 转面图**，之后所有动作视频都上传这张图做参考，
>    确保任何动作下毛色、花纹、五官、身体比例完全一致。

| 步骤 | 产物 | 说明 |
|------|------|------|
| ① 形象设定图 | 1 张正面标准站姿图 | 品种毛色由你从下表选一条填入 |
| ② 360° 转面图 | 1 张四格转面图 | 正面/左侧/右侧/背面，一致性锚点 |

## 第二步：360° 转面图（动作一致性的锚点）

> 这一步是**强制项**。转面图确定后，第三步每段动作视频都要把这张图作为
> 参考图上传给豆包，并在提示词里注明「与参考图中的猫完全一致」。

### 模板（替换 `【毛色】` 后发送）

```text
同一只Q版小猫的360度转面设定图，四格并列，从左到右依次为：
第一格正面视角、第二格左侧面视角、第三格右侧视角、第四格背面视角。
猫咪形象：【毛色】。
四格必须是同一只猫：毛色花纹分布完全一致，五官完全一致，
身体比例完全一致，大小完全一致，仅视角不同。
每一格中猫咪均为正常四足站立姿态，尾巴自然竖起微弯，全身完整无遮挡。
纯白背景，无文字，无标注，无水印，高清渲染。
```

### 生成后自检（不满意就重生成）

- 四格是不是**同一只猫**（花纹位置、眼睛颜色、比例一致）？
- 侧面和背面是否完整（尾巴、背部花纹清晰可见）？
- 后续动作主要用到**正面**和**左侧面**，这两格必须最清晰。

## 第三步：动作视频提示词（绿幕 10 秒）

### 使用方法

1. 每段动作 = **通用前缀 + 该动作的概述与按秒分解**，整段复制发给豆包视频生成。
2. **上传第二步的转面图作为参考图**（豆包视频支持首帧/参考图时，用第一格正面站姿裁剪图作首帧参考）。
3. 一段动作生成一条 10 秒视频，按动作名保存。

### 通用前缀（每段动作都必须完整带上）

```text
【绝对空间与边界约束强制命令】
视频比例16:9，背景必须为纯粹的绿幕色（标准 Chroma Key Green，颜色严格统一为 #00FF00），
无任何阴影、杂物、渐变或边框，背景本身即为单一纯色块。
【角色一致性强制命令】
主角为参考图中的同一只Q版小猫，正常四足猫咪身体结构，不直立行走，不穿衣戴帽。
毛色花纹、五官、眼睛颜色、身体比例必须与参考图完全一致，全片不允许有任何偏差。
【角色位置与大小强制固定】
猫咪必须完完全全处于画面正中心偏下位置。四爪落地点始终处于画面垂直方向约85%的位置，
站立时头顶始终处于画面垂直方向约20%的位置，身体最左最右边缘始终处于画面水平方向
约25%和75%的位置。不同视频之间的角色大小、位置、比例必须完全一致，不允许有任何偏差。
【画幅安全红线（全程强制）】
动作全程任何一帧，猫咪任何身体部位（耳朵尖、尾巴尖、胡须、爪尖）
以及所有道具与特效对象，在最高点最外点都必须与画幅对应边缘保持
至少10%画幅宽高的安全间距；绝对禁止任何部位或对象接触、超出或被画幅边缘裁剪。
【绝对居中锚点（强制）】
猫咪四爪落点坐标恒定为画面水平正中央，全程不允许产生水平方向的位移
（仅允许原地重心下沉、原地起跳后落回原点、原地转身）。
严禁为了构图把猫咪整体向左右移动或靠向画幅边缘。
【首尾帧规则（强制）】
所有视频必须以参考图正面格的标准四足站姿为第一起始帧（画面干净、无道具无特效），
并在视频最后一秒彻底恢复到与第一帧完全一致的标准四足站姿，无道具残留、无特效残留。
【画面干净（强制）】
无文字、无水印、无字幕、无阴影投射在绿幕上；除提示词明确要求的特效外，
画面中不得出现任何其他物体。
```

> 提醒：发给豆包时，通用前缀和动作段落之间不要空行断开，直接连成一段效果更好。

### 动作 1：待机呼吸（idle）

```text
【动作概述】
Q版小猫四足站立在画面中央原地，身体随呼吸有节奏地轻微上下起伏，
胸口和背部缓慢隆起再放平。双眼圆睁平视前方，每隔约2秒轻快地眨眼一次，
眨眼时上下眼睑完全合拢再睁开。耳朵偶尔轻轻转动一下方向，
尾巴竖起并在尾尖做非常小幅度的左右摆动。四爪全程固定在原地不动。
【按秒分割画面】
0~3秒：身体以极轻微幅度上下起伏，模拟呼吸，约第2秒眨眼一次。
3~7秒：头部以极小幅度向左再向右缓慢转动，仿佛在环顾四周，
耳朵随头部方向轻轻转动，尾巴尖小幅摆动，四爪原地不动。
7~10秒：头部缓缓回正，眨眼一次，呼吸恢复平稳。
第10秒结束时，与第一帧的标准四足站姿完全一致。
```

### 动作 2：玩毛线球（playing）

```text
【动作概述】
一颗朱红色的毛线球出现在猫咪面前的地面上（位于猫咪身前正中，
不遮挡猫咪身体）。猫咪压低前身，抬起一只前爪反复轻拍毛线球，
毛线球被拍得向一侧滚动一小段又被猫咪伸爪勾回来，来回两三次。
猫咪双眼圆睁紧盯毛线球，瞳孔放大，耳朵向前竖起，尾巴绷直微微左右摆动，
表现出专注又兴奋的状态。动作结束后毛线球停在猫咪爪边静止。
【按秒分割画面】
0~2秒：标准四足站姿，视线落向身前地面，身体开始压低。
2~3秒：一颗朱红色毛线球从猫咪身前的地面上滚动进入画面中央。
3~7秒：猫咪抬起右前爪连续轻拍毛线球两次，毛线球向左滚出一小段，
猫咪伸左前爪把球勾回原位，再拍一次；全程四爪落点基本不动，
仅前爪和上身活动，尾巴绷直小幅摆动。
7~10秒：猫咪收回前爪，毛线球停在爪边静止，猫咪抬头回正，
恢复标准四足站姿。毛线球保留在画面中（这是本动作的道具）。
```

### 动作 3：原地跑酷（parkour）

```text
【动作概述】
猫咪在原地做出轻快的小跑姿态：四爪交替小幅度抬起落下，
像在跑步机上原地小跑，背部随步伐轻微起伏，耳朵向后收拢，
尾巴向后平伸并随节奏摆动。双眼圆睁目视前方，状态轻快有活力。
全程四爪落点保持在画面中心附近，不向前冲也不后退。
【按秒分割画面】
0~2秒：标准四足站姿，重心微微下沉，做出蓄力预备姿态。
2~7秒：四爪开始原地交替小跑，节奏由慢到快再保持匀速，
背部随步伐自然起伏，尾巴向后平伸摆动，耳朵向后收。
7~10秒：步伐逐渐放缓直至停止，四爪并拢落定，
尾巴从后伸状态收回竖起，恢复标准四足站姿。
```

### 动作 4：开心蹦跳（happy，被摸头时播放）

```text
【动作概述】
猫咪原地向上轻快地小跳两下，四爪同时离地再同时落回原点，
每次落地时身体轻微下沉再弹起。跳的时候双眼弯成两道月牙，
嘴角轻轻上扬，耳朵直立微微前倾，尾巴高高竖起大幅摆动。
第二跳落地站稳后，猫咪仰起头朝向镜头方向，尾巴尖愉快地卷起。
【按秒分割画面】
0~2秒：标准四足站姿，身体微微下沉蓄力，尾巴开始上竖。
2~5秒：第一次原地小跳，四爪同时离地约一个爪位高度后落回原点，
落地时身体轻微压缩再弹起；紧接着第二次小跳，幅度与第一次相同。
5~7秒：站稳，身体从压缩状态完全弹开站直，
双眼弯成月牙，耳朵前倾，尾巴高高竖起摆动。
7~10秒：猫咪仰头朝向镜头，尾巴尖卷起，保持愉快的站姿，
呼吸起伏逐渐平稳。第10秒结束时恢复标准四足站姿。
```

```text
猫咪背部高高弓起，全身毛发蓬松炸开，四条腿绷直使身体整体抬高，
```

### 动作 6：伸懒腰（stretch，睡醒时播放）

```text
【动作概述】
猫咪做经典的猫式伸懒腰：前身趴低，两只前爪向正前方远远伸出，
胸口和下巴贴近地面，背部下压凹陷，屁股高高撅起，尾巴向上翘起。
保持这个拉伸姿态几秒，双眼半眯，耳朵放松微微向两侧。
随后缓慢收爪，脊柱一节节拱回，最后站直并轻轻抖动一下全身毛发。
【按秒分割画面】
0~2秒：标准四足站姿，前爪开始向前挪动，前身缓缓下沉。
2~6秒：完成猫式伸展：前爪向正前方伸直，胸口下巴贴向地面，
背部下压，屁股抬起，尾巴向上翘起微微晃动，双眼半眯。
6~9秒：前爪收回，背部拱起，身体一节节抬起站直，
站立后全身轻微抖动一下把毛发抖顺。
9~10秒：恢复标准四足站姿，眨眼一次，呼吸平稳。
```

```text
猫咪抬起头舔了一下嘴边，嘴角沾着一粒猫粮。
【按秒分割画面】
0~2秒：标准四足站姿，一碗盛满的朱红色猫粮碗从画面下方
出现在猫咪身前正中的地面上。
2~8秒：猫咪前身趴低，低头进食，腮帮随咀嚼鼓动，
每咬两三口抬头换一口气再继续，尾巴平缓摆动。
8~10秒：猫咪抬头，舔一下嘴边，碗里猫粮明显变少，
恢复标准四足站姿。猫粮碗保留在画面中。
```

### 动作 11：睡觉·入睡段（sleep_start）

> 睡觉是三段接力：入睡（10秒，站姿→睡姿）、循环（10秒，睡姿→同一睡姿，
> 可无缝循环）、醒来（10秒，睡姿→站姿）。三段的**睡姿必须完全相同**。

```text
【动作概述】
猫咪先站着打哈欠：嘴巴张大露出粉色舌头和小尖牙，眼眶泛起泪光，
前身下压做一个小伸展。随后眼皮越来越沉，四腿缓缓弯曲，
身体重心下沉，最后在原地蜷成一团趴下：四爪收在身下，
尾巴绕到身前搭在身侧，脑袋轻轻搁在前爪上，双眼完全闭合。
全程在原地完成，不水平移动。
【按秒分割画面】
0~2秒：标准四足站姿，张嘴打一个大哈欠，
眼眶泛起泪光，耳朵微微下垂。
2~5秒：眼皮逐渐耷拉闭合，四腿开始弯曲，重心缓缓下沉。
5~9秒：完全趴下蜷成一团：四爪收在身下，尾巴绕到身前搭在身侧，
脑袋搁在前爪上，双眼闭合，只有呼吸的轻微起伏。
9~10秒：保持蜷缩睡姿完全静止。
本段最后10秒内的睡姿必须与下一段循环段的睡姿完全一致。
全程不出现任何文字。
```

### 动作 12：睡觉·循环段（sleep_loop）

```text
【动作概述】
猫咪蜷成一团趴在原地睡觉：四爪收在身下，尾巴绕到身前搭在身侧，
脑袋搁在前爪上，双眼闭合。整段近乎静止，只有背部和身体两侧
随呼吸极缓慢地起伏，耳朵偶尔极轻微地颤动一下。
头顶上方缓缓冒出一个半透明的小气泡图形，气泡内没有文字，
气泡缓缓上升后在片段结束前完全淡出消失。
最后一帧与第一帧的姿态完全相同，保证循环播放时不跳动。
【按秒分割画面】
0~1秒：蜷缩睡姿完全静止，画面干净无气泡。
1~4秒：缓慢吸气，背部极轻微抬起，一个半透明小气泡
从头顶上方冒出并缓缓上升。
4~7秒：缓慢呼气，身体回到最低点，气泡继续上升。
7~9秒：气泡完全淡出消失，身体只剩呼吸起伏。
9~10秒：呼吸回到起始相位，姿态与第0秒逐帧一致。
全程双眼闭合，禁止抬头、禁止起身、禁止位移、禁止出现任何文字。
```

### 动作 13：睡觉·醒来段（sleep_wake）

```text
【动作概述】
猫咪保持蜷缩睡姿几秒后，双眼缓缓睁开，耳朵先立起来，
脑袋抬起，前爪向前伸展做一个猫式伸懒腰，背部下压，
随后拱背起身，四腿撑地站直，全身轻轻抖动一下，
尾巴竖起甩动一下，最后恢复标准四足站姿。
【按秒分割画面】
0~3秒：蜷缩睡姿静止，呼吸起伏，与循环段的睡姿完全一致。
3~5秒：双眼缓缓睁开，耳朵立起，脑袋抬起离开前爪。
5~8秒：前爪向前伸展做猫式伸懒腰，背部下压后拱起，
四腿发力缓缓站起。
8~10秒：完全站直，全身轻微抖动一下，尾巴竖起甩动，
恢复标准四足站姿，与第一帧站姿完全一致。
全程不出现任何文字。
```

### 动作 14：被拖拽悬空（drag，可选）

```text
【动作概述】
猫咪被无形的力量从身体上方提起，四爪完全离地悬空，
身体自然舒展下垂，四条腿轻轻垂下，尾巴向下垂并轻微晃动。
双眼圆睁，瞳孔放大，耳朵微微向两侧张开，表情惊愕。
身体保持轻微的左右小幅摆动，像挂在空中的样子。
【按秒分割画面】
0~2秒：标准四足站姿突然僵住，随即四爪离地被提起，
四肢自然下垂，眼睛圆睁。
2~7秒：悬空状态，身体轻微左右摇摆，尾巴下垂晃动，
四爪轻轻划动两下。
7~10秒：缓缓下降，四爪落回原来的落点，恢复标准四足站姿。
```

## 第四步：素材规格与程序接入

### 生成后的检查清单（每段视频）

- [ ] 背景是纯净 #00FF00 绿幕，无阴影无杂物
- [ ] 猫咪大小、位置与转面图一致，动作全程没被画幅裁切（含尾巴尖、耳尖）
- [ ] 首帧和尾帧都是标准四足站姿（睡觉三段除外）
- [ ] 无文字、无水印
- [ ] 毛色花纹与转面图完全一致

### 抠绿幕转透明（本地处理，dsh-pet 同款管线）

```sh
# 需要 Python3 + ffmpeg + numpy
# 简化版：绿幕抠像并导出透明 PNG 序列帧（供程序逐帧播放）
python tools/chroma_key.py 输入.mp4 输出目录/ --color 00FF00
```

> dsh-pet 的完整素材链（水印处理→HSV抠像→归一化→转码）开源在
> github.com/PC2005-cloud/dsh-pet 的 `scripts/` 目录，可直接借用。

### 目标交付格式（给程序接入用）

| 项目 | 规格 |
|------|------|
| 目录 | `ui/pet_sprites/{品种id}/`，如 `ui/pet_sprites/orange/` |
| 命名 | `{动作名}.webm`（带透明通道 VP9）或 `{动作名}/0001.png` 序列帧 |
| 动作名 | idle / playing / parkour / happy / angry / stretch / hungry / eating / drinking / look_around / sleep_start / sleep_loop / sleep_wake / drag |
| 脚底线 | 所有动作的爪底对齐同一水平线（程序按底边对齐摆放） |
| 品种id | orange / lihua / calico / ragdoll / british / silver / golden / devon / dog |

程序侧计划：`PetWidget` 增加「精灵模式」——检测到对应品种目录即播放
图片序列/webm，未检测到则回退到现有的程序化 2D 绘制，两套并存互不影响。
