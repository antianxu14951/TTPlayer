# TT播放器

TT播放器（内部代号 `MusicPlayer`）是一款桌面音乐播放器，界面分为左侧导航栏、顶部操作栏、中央曲目列表与底部播放栏。支持本地与抖音音乐导入、聚合搜索、歌单管理和播放控制。

## 已实现功能

1. **导入音乐**：支持多选导入 mp3、wav、flac、m4a、aac、ogg、wma、opus 等格式，自动按路径去重；也可粘贴抖音分享口令，在同一个对话框里选好目标歌单并粘贴口令，程序会自动完成解析、下载、转码并入库。导入进度实时显示，失败会给出原因，成功即关闭窗口，不留中间状态。
2. **播放模式**：列表循环、随机播放（避免连续播放同一首）、单曲循环（播完自动从头重播）。
3. **歌单管理**：左侧栏只列歌单，系统自带一个不可重命名、不可删除的「默认歌单」。可新建、重命名、删除歌单；单击打开歌单，双击播放整单，双击曲目播放单曲。删除歌单会同时清理媒体库记录，但保留磁盘上的音频文件；与其他歌单共享的曲目只从当前歌单移除。曲目右键可以移出歌单、移出媒体库或删除文件（不可恢复），删除正在播放的曲目会先停止播放再删文件，避免文件被占用。
4. **聚合搜索**：在顶栏输入关键词并回车，会同时检索所有已安装音源并合并显示结果；界面不显示具体平台名称。鼠标移到结果上出现播放按钮，单击或双击可试听，试听不会改动正在播放的队列。右键结果可「添加到播放列表」或「添加到歌单」，确认后才下载入库。音源脚本放在 `sources/` 目录，每次启动自动扫描加载，新增或修改的脚本下次启动生效。音源数据来源由使用者自行配置并负责其合法性。
5. **播放控制**：播放/暂停、上一首、下一首、进度点击与拖动、音量调节（点击或拖动均可）、输出设备切换、模式切换。最近播放的歌单、曲目、进度、音量与所选设备会在下次启动时自动恢复。播放栏右下角的队列按钮可展开「正在播放」列表，双击跳转，右键移除或清空。
6. **界面与设置**：浅色主题，靛蓝主色与扁平小圆角卡片。顶栏「设置」可修改数据库位置（保存时自动迁移现有数据）、缓存目录、FFmpeg 路径、解析与下载超时、重试次数和优先清晰度等。删除完成、导入完成等提醒框 3 秒后自动关闭；删除歌单、删除文件、清空队列等确认框仍需手动确认。
